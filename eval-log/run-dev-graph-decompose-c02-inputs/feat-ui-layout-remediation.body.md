# 全画面の UI 崩れ是正と折返し位置の意図化・印刷導線の非表示

## 0. なぜこの feature があるのか

利用者の指摘は 2 段構えである。1 つは「変なところで改行がある」、もう 1 つは「**2 行で表現するなど、端から 2 行で表現する工夫にしてほしい**」だった。

つまり求められているのは折返しの**禁止**ではなく、折返し**位置の意図化**である。`削減効/果` のように語の途中で割れるのを、`使用状況・` / `削減効果` のように意味の切れ目で割る。折返しを禁止 (nowrap) すると狭い画面で横に溢れるだけで、症状が別の形に移るにすぎない。

印刷導線については利用者が「今のところ使用する用途が考えられないので一旦不要、非表示に」と述べた。全ページ印刷は将来課題として起票するに留め、本 feature では実装しない。

## 1. 目的

サイドバーの「使用状況・削減効果」が語の途中で `削減効` と `果` に割れるなど、折返し位置が意味の切れ目と一致していない箇所が画面全体に散在している。折返しを禁止すると狭い画面で横に溢れるだけで症状が移動するため、折返しを許したまま位置を意図した箇所へ固定し、同種の箇所を全画面で洗い出して揃える。あわせて、現時点で用途の無い印刷導線を利用者の判断により非表示にする。

## 2. ゴール

自動検査 (feat-ui-integrity-audit-harness) が検出した全画面の崩れが 0 件になり、複数行になる文言が意味の切れ目で折り返され、印刷導線が利用者から見えない状態。

## 3. 含むもの

- 自動検査が検出した横溢れ・タップ域不足・意図しない折返しの全件是正
- 折返し位置の意図化 (語中で割れる文言を意味の切れ目で 2 行にする)
- 同種の折返し問題の全画面での洗い出しと、発見箇所の一覧化
- 折返し位置の指定手段を共通 UI 側へ寄せ、画面ごとの場当たり対応にしない
- 印刷導線 (印刷画面・印刷ボタン) の非表示化
- 非表示にした印刷導線が経路として残らないことの確認
- 全ページ印刷を将来課題として課題トラッカーへ起票 (実装はしない)

## 4. 含まないもの

- 全ページ印刷の実装 (将来課題として起票のみ)
- 検査基盤そのものの実装 (feat-ui-integrity-audit-harness の担当)
- 配色・テーマの変更 (feat-theme-palette-catalog の担当)
- 情報設計・画面構成の変更 (崩れの是正であり再設計ではない)
- 新規画面の追加
- 折返しを nowrap で禁止する方針 (利用者が明示的に 2 行表現を求めたため採らない)

## 5. 受入基準

- 自動検査が全 28 route × 3 幅 × 2 テーマで横溢れ 0 件・タップ域違反 0 件・意図しない折返し 0 件を報告する
- サイドバーの「使用状況・削減効果」が 360px 幅で `使用状況・` / `削減効果` の 2 行に折り返される
- 語中で割れていた文言の一覧が作成され、全件について是正後の折返し位置が記録されている
- 折返し位置の指定が共通 UI 側の仕組みで行われ、画面ごとの個別 CSS の複製になっていない
- 印刷導線が全画面から表示されず、直接 URL でも印刷画面へ到達しない
- 全ページ印刷が将来課題として課題トラッカーに起票され、本 feature の完了条件から外れている
- 是正によって既存の自動検査・単体テストが非退行である
