# 通知メール

## 目的

ユーザーが重要なイベントを確認できるようにメール通知で情報を届ける。

## 到達状態

ユーザー登録完了時と重要な変更時に自動でメール通知が送信される状態。

## スコープ

### スコープ内

- 登録完了時メール送信
- 重要変更イベント検出
- メールテンプレート実装
- SMTP統合

### スコープ外

- メール配信SLA管理
- SPF/DKIM設定
- SMS通知

## 受入条件

- 登録直後に確認メールが送信される
- 重要な設定変更時に通知メールが送信される
- 送信失敗時に再試行を実施
