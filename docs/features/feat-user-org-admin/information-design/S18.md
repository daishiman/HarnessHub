# S18 アカウント設定 情報設計シート

## 利用文脈

全ロール。自分の表示名を直す・通知を減らす・見た目を変える、のいずれか **1 つだけ**をしに来る。3 つの用が同時に発生することはほとんどない。端末は wide / narrow の両方。

## 画面プロファイル

Surface: `S18.ACCOUNT` / route: `/settings/account`。role、task-mode、density、wide/middle/narrow pattern、sticky policy は `docs/screen-inventory.md` の同 surface 行だけを正本とする。

## 表示項目とグループ

| 面 | 項目 | 表示加工 | 可視ラベル | accessible name/description |
|---|---|---|---|---|
| プロフィール | メールアドレス / 部門 | 読み取り専用。「管理者が変更します。」の補足つき | 用語 | 用語 + 説明 + 補足 |
| プロフィール | 表示名 | 入力欄。説明「画面右上や一覧に表示される名前です。」 | 「表示名」 | ラベル + 説明 |
| 通知設定 | 生成完了 / レビュー依頼 / 週次レポート / フィードバック依頼 / メール通知チャンネル | 「有効」「無効」の選択欄。選ぶとすぐ保存 | 各項目名 | ラベル |
| 表示設定 | テーマ / 表示密度 / 言語 | 選択欄。選ぶとすぐ保存し、その場で反映 | 各項目名 | ラベル |

自分では変えられない項目 (メールアドレス・部門) を**隠さずに出す**。隠すと「この画面では変えられない」のか「そもそも設定が無い」のかが区別できず、管理者に依頼すればよいことに辿り着けない。補足で誰が変えるかまで書く。

3 つの面はそれぞれ別の保存先を持つ。**結果もその面の中に返す。** 画面上端にまとめて出すと、「どの操作の結果なのか」が読み手の推測に委ねられる。

## pattern 選定

| 候補 / hybrid | 必要 task capability への適合 | 弱点 | a11y/fallback | 判定 |
|---|---|---|---|---|
| 面 3 つの縦積み | 1 つの用だけを済ませて帰る使い方に合う。面の見出しで目当てに直行できる | 縦に長い | 各面に `id` を持たせ、通知ベルなどから直接飛べる | **採用** |
| タブ | 面を切り替えられるが、3 面しかなく、切り替えの操作が 1 手増えるだけになる | — | — | 不採用 |
| 1 つのフォームにまとめて末尾に保存ボタン | 保存先が 3 つに分かれているため、1 つ失敗したときの扱いが決められない | — | — | 不採用 |

読み取り専用の項目は**定義リスト**で並べる。1 つの対象 (自分) の属性を並べる箇所なので、表を使わない。

## 保存の作法

| 面 | 作法 | 理由 |
|---|---|---|
| プロフィール | 入力 → 「表示名を保存する」で確定 | 自由入力なので、打っている途中の値を送らない |
| 通知設定 | 選ぶとすぐ保存 | 選択肢が 2 つしかなく、押した時点で意思が確定している |
| 表示設定 | 選ぶとすぐ保存し、その場で画面へ反映 | 見た目の設定は結果を見て判断するもので、保存を挟むと確かめられない |

自由入力と選択で作法が違うことを、面の説明文にも書く (「変更するとすぐ保存されます。」)。

## 削った情報

- **ロール** — 自分では変えられず、変える依頼先も部門・メールと同じ管理者。3 つ並べても情報が増えない。
- **パスワード変更** — 外部の認証基盤に任せており、この画面に出口を作ると二重管理になる。
- **通知の履歴** — 設定の画面であり、届いた知らせの一覧は別の役割。

## 視覚要素の意味契約

| 要素 | 採用/省略 | 伝える意味 | a11y 代替 |
|---|---|---|---|
| label | 採用 | 入力欄のラベルと説明。読み取り専用項目も用語 + 説明で組む | `<label>` / `<dt>/<dd>` |
| line | 採用 | 面の枠のみ | — |
| space | 採用 | `comfortable`。設定画面なので詰めない | — |
| icon | 省略 | 成否は見出しの語で言い分ける (「更新しました」「保存できませんでした」)。色だけに頼らない | — |
| alignment | 採用 | すべて先頭揃え | — |
| repetition | 採用 | 面の形・保存の結果表示を他の設定画面と揃える | — |

読み込みの失敗だけが画面全体を置き換える。保存の失敗ではその分岐に入らない (入力中の値を消さない)。

## 成功指標と証跡境界

- 代表タスク: 「週次レポートの通知だけを止める」。
- machine gate (現行): `UOA-A11Y-006` (選択欄の契約)、a11y テスト、表示設定の保存後にリロードなしで反映されること。
- manual gate: 3 つの面のどれで保存しても、結果がその面の中に出ること。
- future gate (予定): チェックボックス / スイッチ部品の導入。現状は共通部品に無いため選択欄で代用している。
